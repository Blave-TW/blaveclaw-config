  TIME CONVENTION — convert before typing any HHmm value:
             Blave index = bar OPEN time, UTC (13:25–13:30 Taipei bar = 05:25Z).

             last bar Time = 1345.
  Flat rule: `FlatTime` is compared against bar-close time and the exit fires
             `next bar at market`, so pick FlatTime a few bars BEFORE the session
             end (1340 on a 1-min chart exits at the open of the 13:41 bar).
             Do NOT use SetExitOnClose (backtest-only in MC) or
             `this bar on close` (live/backtest mismatch) for this.
  Timing   : decision at bar close, fill at next bar open.

Inputs:
    FastLen(20),
    SlowLen(50),
    StartTime(0900),       // HHmm, chart time, bar-close basis — no trades before
    EndTime(1300),         // HHmm — no NEW entries at or after this
    FlatTime(1340),        // HHmm — force flat from this bar-close onward
    Qty(1);

Variables:
    FastMA(0),
    SlowMA(0),
    InWindow(false),
    MustFlat(false);

// --- indicators ---
FastMA = Average(Close, FastLen);
SlowMA = Average(Close, SlowLen);

// --- signal ---
InWindow = Time >= StartTime and Time < EndTime;
MustFlat = Time >= FlatTime;
Condition1 = FastMA > SlowMA and InWindow;         // Blave: signal = 1.0 inside window
Condition2 = FastMA < SlowMA;                      // Blave: signal = 0.0

// --- orders ---
// Flat rule first: it must win over any entry generated on the same bar.
if MustFlat and MarketPosition <> 0 then begin
    Sell ("EOD_LX") next bar at market;
    BuyToCover ("EOD_SX") next bar at market;
end;

if Condition1 and MarketPosition <= 0 and MustFlat = false then
    Buy ("LE") Qty contracts next bar at market;

if Condition2 and MarketPosition = 1 then
    Sell ("LX") next bar at market;
